# DJI Cloud API Web 项目启动指南

## 项目概述

这是一个基于Vue 3 + TypeScript + Vite构建的DJI Cloud API Web演示项目，主要用于展示如何通过Web端与DJI设备进行交互，包括无人机控制、机场管理、地图操作、直播流等功能。

## 技术栈

- **前端框架**: Vue 3.2.26
- **构建工具**: Vite 2.4.0
- **开发语言**: TypeScript 4.5.4
- **UI组件库**: Ant Design Vue 2.2.8
- **状态管理**: Vuex 4.0.2
- **路由管理**: Vue Router 4
- **地图服务**: 高德地图 (@amap/amap-jsapi-loader)
- **实时通信**: MQTT 4.3.7, WebSocket
- **直播流**: Agora RTC SDK, RTMP/RTSP/GB28181
- **样式预处理**: SCSS

## 环境要求

- Node.js >= 14.0.0
- npm >= 6.0.0 或 yarn >= 1.22.0
- 现代浏览器 (Chrome, Firefox, Safari, Edge)

## 安装步骤

### 1. 克隆项目
```bash
git clone <repository-url>
cd dji-sdk/dji-web
```

### 2. 安装依赖
```bash
# 使用 npm
npm install

# 或使用 yarn
yarn install
```

### 3. 配置环境变量
在项目根目录创建环境配置文件：

#### 创建 `.env.development` 文件
```env
# 开发环境配置
VITE_APP_ID=your_app_id
VITE_APP_KEY=your_app_key
VITE_APP_LICENSE=your_app_license
VITE_BASE_URL=http://your-backend-url:port/
VITE_WEBSOCKET_URL=ws://your-backend-url:port/api/v1/ws
VITE_RTMP_URL=rtmp://your-streaming-server/live/
VITE_AMAP_KEY=your_amap_key
VITE_AGORA_APP_ID=your_agora_app_id
VITE_AGORA_TOKEN=your_agora_token
VITE_AGORA_CHANNEL=your_agora_channel
```

#### 创建 `.env.production` 文件
```env
# 生产环境配置
VITE_APP_ID=your_prod_app_id
VITE_APP_KEY=your_prod_app_key
VITE_APP_LICENSE=your_prod_app_license
VITE_BASE_URL=https://your-prod-backend-url/
VITE_WEBSOCKET_URL=wss://your-prod-backend-url/api/v1/ws
VITE_RTMP_URL=rtmp://your-prod-streaming-server/live/
VITE_AMAP_KEY=your_prod_amap_key
VITE_AGORA_APP_ID=your_prod_agora_app_id
VITE_AGORA_TOKEN=your_prod_agora_token
VITE_AGORA_CHANNEL=your_prod_agora_channel
```

### 4. 配置API接口
编辑 `src/api/http/config.ts` 文件，填入正确的API配置：

```typescript
export const CURRENT_CONFIG = {
  // 应用凭证
  appId: 'your_app_id',
  appKey: 'your_app_key', 
  appLicense: 'your_app_license',
  
  // HTTP接口
  baseURL: 'http://your-backend-url:port/',
  websocketURL: 'ws://your-backend-url:port/api/v1/ws',
  
  // 直播流配置
  rtmpURL: 'rtmp://your-streaming-server/live/',
  gbServerIp: 'your_gb_server_ip',
  gbServerPort: 'your_gb_server_port',
  gbServerId: 'your_gb_server_id',
  gbAgentId: 'your_gb_agent_id',
  gbPassword: 'your_gb_password',
  gbAgentPort: 'your_gb_agent_port',
  gbAgentChannel: 'your_gb_agent_channel',
  rtspUserName: 'your_rtsp_username',
  rtspPassword: 'your_rtsp_password',
  rtspPort: '8554',
  agoraAPPID: 'your_agora_app_id',
  agoraToken: 'your_agora_token',
  agoraChannel: 'your_agora_channel',
  
  // 地图配置
  amapKey: 'your_amap_key',
}
```

## 启动项目

### 开发环境
```bash
# 启动开发服务器
npm run serve
# 或
yarn serve
```

项目将在 `http://localhost:8080` 启动

### 生产构建
```bash
# 构建生产版本
npm run build
# 或
yarn build

# 预览生产构建
npm run preview
# 或
yarn preview
```

## 主要功能模块

### 1. 用户认证
- 登录页面 (`src/pages/page-web/index.vue`)
- 支持Web端和飞手端登录
- Token认证机制

### 2. 设备管理
- 设备列表展示
- 设备状态监控
- 设备控制面板
- 设备升级管理

### 3. 地图功能
- 高德地图集成
- 实时设备位置显示
- 地图绘制工具（点、线、面）
- 飞行区域管理

### 4. 无人机控制
- 实时OSD数据显示
- 飞行控制指令
- 载荷控制
- 机场控制

### 5. 直播流
- 多种直播协议支持（RTMP、RTSP、GB28181）
- Agora RTC集成
- 实时视频流播放

### 6. 任务管理
- 航线规划
- 任务创建和执行
- 任务状态监控

## 开发注意事项

### 1. 环境配置
- 确保所有必要的API密钥和配置都已正确设置
- 开发环境需要配置HTTPS才能使用某些Web API

### 2. 跨域问题
- 开发环境已配置代理，生产环境需要后端支持CORS

### 3. 地图服务
- 需要申请高德地图API Key
- 确保地图服务配置正确

### 4. 直播流
- 需要配置相应的流媒体服务器
- Agora服务需要申请相应的App ID和Token

### 5. MQTT连接
- 确保MQTT服务器可访问
- 检查连接配置和认证信息

## 常见问题

### 1. 启动失败
- 检查Node.js版本是否符合要求
- 清除node_modules重新安装依赖
- 检查端口8080是否被占用

### 2. 地图不显示
- 检查高德地图API Key是否正确
- 确认网络连接正常
- 检查浏览器控制台错误信息

### 3. 设备连接失败
- 检查后端服务是否正常运行
- 确认MQTT连接配置
- 检查设备网络连接

### 4. 直播流无法播放
- 检查流媒体服务器配置
- 确认直播协议设置正确
- 检查浏览器对相应协议的支持
