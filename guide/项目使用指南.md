# DJI Cloud API Web 项目使用指南

## 项目概述

这是一个基于Vue 3 + TypeScript + Vite构建的DJI Cloud API Web演示项目，主要用于展示如何通过Web端与DJI设备进行交互，包括无人机控制、机场管理、地图操作、直播流等功能。

## 技术栈

- **前端框架**: Vue 3.2.26
- **构建工具**: Vite 2.4.0
- **开发语言**: TypeScript 4.5.4
- **UI组件库**: Ant Design Vue 2.2.8
- **状态管理**: Vuex 4.0.2
- **路由管理**: Vue Router 4
- **地图服务**: 高德地图 (@amap/amap-jsapi-loader)
- **实时通信**: MQTT 4.3.7, WebSocket
- **直播流**: Agora RTC SDK, RTMP/RTSP/GB28181
- **样式预处理**: SCSS

## 环境要求

- Node.js >= 14.0.0
- npm >= 6.0.0 或 yarn >= 1.22.0
- 现代浏览器 (Chrome, Firefox, Safari, Edge)

## 快速开始

### 1. 安装依赖
```bash
# 使用 npm
npm install

# 或使用 yarn
yarn install
```

### 2. 配置环境变量
在项目根目录创建环境配置文件：

#### 创建 `.env.development` 文件
```env
# 开发环境配置
VITE_APP_ID=your_app_id
VITE_APP_KEY=your_app_key
VITE_APP_LICENSE=your_app_license
VITE_BASE_URL=http://your-backend-url:port/
VITE_WEBSOCKET_URL=ws://your-backend-url:port/api/v1/ws
VITE_RTMP_URL=rtmp://your-streaming-server/live/
VITE_AMAP_KEY=your_amap_key
VITE_AGORA_APP_ID=your_agora_app_id
VITE_AGORA_TOKEN=your_agora_token
VITE_AGORA_CHANNEL=your_agora_channel
```

### 3. 启动项目
```bash
# 启动开发服务器
npm run serve
# 或
yarn serve
```

项目将在 `http://localhost:8080` 启动

## 主要功能模块

### 1. 用户认证与登录
- **登录页面**: `src/pages/page-web/index.vue`
- **支持模式**: Web端和飞手端登录
- **认证机制**: Token认证
- **路由保护**: 基于路由的权限控制

### 2. 设备管理
- **设备列表**: 展示所有连接的DJI设备
- **设备状态**: 实时监控设备在线状态
- **设备控制**: 提供设备控制面板
- **固件升级**: 设备固件升级管理
- **HMS日志**: 设备健康管理系统日志

### 3. 地图功能
- **地图服务**: 集成高德地图API
- **实时位置**: 显示设备实时位置
- **绘制工具**: 支持点、线、面绘制
- **飞行区域**: 飞行区域管理和限制
- **图层管理**: 多图层叠加显示

### 4. 无人机控制
- **OSD数据**: 实时飞行数据显示
- **飞行控制**: 起飞、降落、返航等指令
- **载荷控制**: 云台、相机控制
- **机场控制**: 机场设备管理
- **任务执行**: 航线任务执行

### 5. 直播流功能
- **多协议支持**: RTMP、RTSP、GB28181
- **Agora RTC**: 集成Agora实时音视频
- **实时播放**: Web端实时视频流播放
- **流媒体管理**: 直播流状态管理

### 6. 任务管理
- **航线规划**: 可视化航线规划
- **任务创建**: 创建和执行飞行任务
- **任务监控**: 实时任务状态监控
- **任务历史**: 任务执行历史记录

### 7. 媒体管理
- **文件管理**: 媒体文件上传下载
- **格式支持**: 支持多种媒体格式
- **预览功能**: 媒体文件预览
- **批量操作**: 批量下载和管理

## 常见问题解决

### 1. 启动问题
- **端口占用**: 检查8080端口是否被占用
- **依赖问题**: 删除node_modules重新安装
- **Node版本**: 确保Node.js版本>=14.0.0

### 2. 地图问题
- **API Key**: 检查高德地图API Key是否正确
- **网络问题**: 确认网络连接正常
- **控制台错误**: 查看浏览器控制台错误信息

### 3. 设备连接问题
- **后端服务**: 检查后端服务是否正常运行
- **MQTT连接**: 确认MQTT连接配置
- **网络连接**: 检查设备网络连接

### 4. 直播流问题
- **流媒体服务器**: 检查流媒体服务器配置
- **协议设置**: 确认直播协议设置正确
- **浏览器支持**: 检查浏览器对相应协议的支持
